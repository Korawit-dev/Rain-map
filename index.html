Rain Map

ยุคของการพยากรณ์ระดับจุลภาคแบบเรียลไทม์ เทคโนโลยีที่สามารถเก็บข้อมูลภาคพื้นได้ในระดับเมตรต่อเมตร ขับเคลื่อนด้วย Supper Algorithm เพื่อชีวิตที่ดีกว่า

About The Project

ปฏิวัติการพยากรณ์อากาศระดับจุลภาค (Microscale Forecasting)

Microscale Forecasting

เรากำลังสร้าง "เครือข่ายวัดอากาศขนาดเล็กระดับจุลภาค" ด้วยกล่องเซนเซอร์อัจฉริยะที่ทุกคนสามารถติดตั้งได้เอง

AI Driven

AI ไม่ใช่เรื่องของอนาคตอีกต่อไป มันคือเครื่องมือทรงพลังที่ขับเคลื่อนธุรกิจในปัจจุบัน

Equality & Accessibility

อุปกรณ์ที่แม่นยำ ทนทาน ประสิทธิภาพสูง ในระดับราคาที่ทุกคนจับต้องได้

Concept: Aial Eye

Aial Eye (ดวงตา)

เซนเซอร์รับภาพและสภาพแวดล้อม

Aial Ear (หู)

รับข้อมูลและสัญญาณจากเครือข่าย

Aial Hand (มือ)

ประมวลผลและตอบสนอง

MCU

ESP8266 NodeMCU

Microcontroller ขนาดเล็ก มี WiFi ในตัว ประมวลผลสูงสำหรับการอ่านค่าจาก Sensor

Sensor

BME280 Sensor

เซนเซอร์วัดอุณหภูมิ ความชื้น และความดันอากาศ แม่นยำ ตอบสนองเร็ว

Sensor

Rain Sensor (YL-83)

เซนเซอร์ตรวจจับหยดน้ำฝนแบบแผ่นตัวนำไฟฟ้า แปลงเป็นสัญญาณ Analog

Battery

TP4056 + Battery

ชิปชาร์จแบตเตอรี่ลิเธียมไอออน มีระบบป้องกันชาร์จเกิน สำหรับวงจรพกพา

Storage

Micro SD Card Module

สำหรับบันทึกข้อมูล (Log) แบบ Offline เชื่อมต่อผ่าน SPI เพื่อเก็บข้อมูลระยะยาว

ชุดคิท Rain Map

สร้างสถานีวัดอากาศของคุณเองได้ง่ายๆ

Code

Open Source API
